Airports

Served from PostgreSQL. Airports are keyed by their FAA identifier (LAX, JFK, 0J0) — not the four-letter ICAO code.

GET /api/v1/airports

Paginated list of airports, with optional filters.

ParameterMeaning
stateTwo-letter state code, e.g. CA
countryTwo-letter country code, e.g. US
cityPartial city name, case-insensitive
qIdentifier prefix, e.g. 0J
page, per_pagePagination; per_page caps at 500
/api/v1/airports?city=chicago&per_page=5
GET /api/v1/airports/<identifier>

One airport with all of its runways. Identifier is case-insensitive.

/api/v1/airports/LAX
GET /api/v1/airports/near

Airports around a point, nearest first. Each result carries a distance_km field.

ParameterMeaning
lat, lonRequired. Decimal degrees
radius_kmSearch radius, default 50, capped at 500
limitMax results, default 20, capped at 200
/api/v1/airports/near?lat=40.7128&lon=-74.0060&radius_km=30  — around New York /api/v1/airports/near?lat=33.9425&lon=-118.4081&radius_km=25&limit=10  — around LAX

Data files

Bulk datasets as gzip-compressed CSV, regenerated by the scraper each FAA cycle. These are file downloads, not JSON.

GET /api/<flag>/

One dataset per flag: b base airports, c class airspace, d obstacles, e special-use airspace, f fixes, g stadiums, n navaids, r runway ends, t TFR.

/api/b/  — base airports (.csv.gz)
GET /api/changes/

Freshness metadata: when each dataset was last updated and how big it is. Clients use this to decide whether to re-download.

/api/changes/

Charts & maps

Airport diagrams and offline map tiles. These are synced from a separate server, so on this instance the listings may be empty.

GET/api/v1/a-big

States that have full FAA airport diagrams; then /api/v1/a-big/<state> for the codes, and /api/v1/a-big/<state>/<code> for the image.

/api/v1/a-big
GET/api/v1/maps

Available offline .mbtiles map packs.

/api/v1/maps

Administration

GET /admin token required

Operator dashboard: dataset freshness, file sizes and manual refresh triggers. Protected — browsers are challenged for credentials, and the JSON endpoints behind it require a bearer token.

Worth knowing

  • Identifiers are FAA codes, not ICAO LAX resolves; KLAX does not. Same for JFK vs KJFK.
  • Coverage follows the FAA source {{ coverage_note }} The dataset is the FAA 28-day subscription, so it is US-centric by construction.
  • Read-only over plain HTTP Every public endpoint is a GET and needs no key. This instance has no TLS certificate yet, so treat it as a staging environment rather than a production integration target.
Data source: FAA National Airspace System Resource (NASR) 28-day subscription.
